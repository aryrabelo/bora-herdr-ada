# omp plugins installed by `just install` (component `omp`).
# One per line: <source> <package-name> [linked=<path under $HOME>]
# <source> is what `omp plugin install` takes (an npm name or github:owner/repo);
# <package-name> is how an existing install is found in `omp plugin list --json`.
# linked= is an extension file that counts as already installed (a hand-linked
# alternative install), so the plugin never loads twice.
# Security review of each entry: README-FORK.md, "Bundled plugins".
